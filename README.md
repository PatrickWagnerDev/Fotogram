# Fotogram

Fotogram is a simple image gallery built as an exam project during the **Frontend Web Developer Bootcamp at Developer Akademie**.

The project is intended for educational purposes only and is not planned for production or deployment.

## Features

* Display a simple image gallery
* Open images in a larger dialog view
* Navigate between images inside the dialog
* Close the dialog and return to the gallery

## Technologies

* HTML
* CSS
* JavaScript
